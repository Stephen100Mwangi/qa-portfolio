# QA Portfolio

A personal portfolio website for a Quality Assurance Engineer focused on automation, API testing, test strategy, and quality engineering.

## Overview

This project showcases:
- QA experience and career journey
- Testing tools and specialties
- Career certifications
- Featured projects and results
- Contact and social links

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Icons
- Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser at the local Vite URL shown in the terminal.

## Production Build

```bash
npm run build
```

## Scripts

- `npm run dev` — run the app locally
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint checks
